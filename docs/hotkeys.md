# Default hotkeys

| Key | Cheat                | Description                                    |
|-----|----------------------|------------------------------------------------|
| F1  | `godmode`            | Freeze player HP at current value              |
| F2  | `infinite_pins`      | Lock puzzle pins at 99                         |
| F3  | `esp_puzzle`         | Overlay puzzle node positions on screen        |
| F4  | `spawn_puzzle_box`   | Re-trigger Lemarchand configuration puzzle     |
| F5  | `one_hit_cenobite`   | Set active cenobite HP to 0 on next hit        |

All keys are rebindable in
`%APPDATA%\HellraiserRevival\trainer.toml` under `[hotkeys]`.
